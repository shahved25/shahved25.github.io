# Ved Shah — Portfolio

Astro static portfolio for https://shahved25.github.io/.

## Local development

Use Node.js 24. Run `npm ci`, `npm run dev`, `npm run check`, and `npm run build`.

## Publish

The GitHub user or organization `shahved25` must own a public repository named `shahved25.github.io`. Upload these files at the repository root. In Settings → Pages, select **GitHub Actions** as the source. Push to `main` to run the included deployment workflow. A successful deploy publishes https://shahved25.github.io/.

Edit `src/data/about.json` for the intro, `src/data/profile.ts` for contact links, and `src/content/` for projects and research.

The original local replica, backups, reference captures, and unused assets are intentionally excluded.
